# Contributing

This repository is published **read-only** as a reference and demo artifact. It is
maintained privately and is **not accepting external contributions**.

- **Issues are disabled.** Bug reports and feature requests are not tracked here.
- **Pull requests will not be reviewed or merged.** You are welcome to fork the
  repository for your own use, but PRs opened against this repo will be closed.

Feel free to clone or fork and adapt the code for your own environment. Thanks for
understanding.
